
# 📚 Teacher Manager App (Flutter)

Aplicativo mobile desenvolvido em **Flutter** com foco em auxiliar professores no gerenciamento completo de suas atividades acadêmicas e acompanhamento de alunos.

## 🚀 Sobre o Projeto

O **Teacher Manager App** é uma solução que centraliza o controle de:

-   Notas dos alunos
    
-   Provas e trabalhos (com datas)
    
-   Faltas
    
-   Participação em aula
    
-   Andamento de atividades
    
-   Eventos e datas importantes
    

Além disso, o aplicativo oferece um **repositório de materiais didáticos** e um **dashboard analítico**, permitindo ao professor acompanhar o desempenho individual e coletivo dos alunos.

----------

## 🎯 Funcionalidades

### 📊 Gestão Acadêmica (CRUD completo)

-   ✅ Cadastro, edição e exclusão de notas
    
-   ✅ Controle de provas e trabalhos com datas
    
-   ✅ Registro de faltas
    
-   ✅ Avaliação de participação
    
-   ✅ Acompanhamento de atividades dos alunos
    
-   ✅ Gestão de eventos escolares
    

### 📁 Repositório de Conteúdos

Organização de materiais por tipo:

-   📄 Arquivos de texto
    
-   📑 PDFs
    
-   🎧 Áudios
    
-   🎥 Vídeos
    

Funcionalidades:

-   Upload de arquivos
    
-   Edição e exclusão
    
-   Organização por categorias
    
-   Acesso total para o professor personalizar os conteúdos
    

### 📈 Dashboard Analítico

-   Desempenho dos alunos
    
-   Análise baseada em critérios definidos pelo professor
    
-   Visualização de progresso individual e geral
    
-   Indicadores e métricas educacionais

##  Como Rodar o Projeto

### Pré-requisitos

-   Flutter instalado
    
-   Dart instalado
    
-   Android Studio ou VS Code
    
-   Emulador ou dispositivo físico
    

### 🔧 Instalação

```bash

git clone https://github.com/seu-usuario/seu-repo.git

# Acesse a pasta do projeto
cd seu-repo

# Instale as dependências
flutter pub add device_preview_plus
flutter pub add get_it

# Execute o projeto
flutter run

```
